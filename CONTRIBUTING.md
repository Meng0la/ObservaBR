# Contribuição
Abra uma mudança pequena por fonte ou recurso. Documente o contrato oficial, licença ou termos aplicáveis, escopo temporal, chave de identidade e como reconhecer dados ausentes. Inclua teste de contrato e teste de reprocessamento. Fixtures devem ser restritas aos testes. Execute npm test, npm run typecheck e npm run build antes de propor a mudança.
